Pemanfaatan Hotspot & Routing MikroTik

Mata Kuliah Jaringan Komputer (Proyek Kelompok 7)

Deskripsi Proyek: Merancang dan membangun infrastruktur jaringan lokal (LAN) serta sistem Hotspot terpusat menggunakan perangkat MikroTik RouterOS dan aplikasi WinBox. Proyek ini bertujuan untuk mendistribusikan koneksi internet secara aman dan terkelola kepada client.

Peran & Tanggung Jawab:

  • Konfigurasi Dasar: Mengatur IP Address pada interface (Ethernet & Wireless) serta konfigurasi Static Route agar terhubung ke ISP.
  • Manajemen Jaringan: Mengonfigurasi DHCP Server untuk pembagian IP otomatis kepada client.
  • Keamanan & Akses: Menerapkan Firewall NAT (Masquerade) agar client dapat mengakses internet, serta pembuatan User Manager pada sistem Hotspot untuk pembatasan akses.
  • Sistem Autentikasi: Membangun halaman Login Hotspot kustom (Voucher/Member) yang terintegrasi dengan sistem Billing (Desa Digital).
  • Pengujian: Melakukan Ping Test dan Speedtest dari sisi client (Laptop/Smartphone) untuk memastikan stabilitas koneksi.

Alat & Teknologi:

MikroTik RouterBoard WinBox Wireless LAN (WLAN) Kabel UTP

Konfigurasi Linux Server & Firewall

Proyek Praktikum / Ujian Praktik

Deskripsi Proyek: Melakukan konfigurasi dan manajemen Router MikroTik secara menyeluruh (mulai dari routing dasar, keamanan firewall, manajemen DHCP, hingga pemblokiran akses web) untuk membangun infrastruktur jaringan laboratorium yang aman, terkontrol, dan sesuai standar operasional.

Peran & Tanggung Jawab:

  • Konfigurasi Dasar Router: Menambahkan lisensi ujicoba, mengubah hostname & password user, serta menamai interface (Internet & LAN) sesuai standar. Mengatur IP Address secara statis pada masing-masing interface.
  • Firewall NAT & Filtering: Membuat konfigurasi Firewall NAT agar client dapat terhubung ke internet. Menerapkan pembatasan akses (Firewall Filter) pada jam operasional tertentu (08.00 - 14.00) dan memblokir akses ke IP tertentu.
  • Keamanan Jaringan: Memblokir Port 8291 (WinBox) dari jaringan lokal untuk mencegah akses tidak sah, serta melakukan uji coba konektivitas jaringan internet dan lokal.
  • Manajemen DHCP: Mengonfigurasi DHCP Server agar client mendapatkan IP otomatis, serta menerapkan pembatasan akses client berdasarkan MAC Address yang terdaftar.
  • Web Proxy & Filtering: Mengaktifkan fitur Web Proxy pada Router untuk memblokir akses ke situs web tertentu (seperti YouTube) dan mencegah pengunduhan file berjenis MP4 oleh client.

Alat & Teknologi:

MikroTik RouterOS WinBox Firewall (NAT & Filter) DHCP Server Web Proxy

Virtualization & Containerization

Proyek Praktikum / Ujian Praktik

Deskripsi Proyek: Membangun dan mengelola lingkungan virtualisasi serta melakukan *deployment* berbagai aplikasi nyata (Nextcloud, Plex Media Server, dan Laravel) menggunakan Docker, Docker Compose, dan Portainer pada sistem operasi Linux Debian 12 (VirtualBox).

Peran & Tanggung Jawab:

  • Setup & Instalasi: Mengonfigurasi Virtual Machine (Debian 12) di VirtualBox, melakukan instalasi Docker Engine, Docker Compose, dan Portainer CE untuk manajemen kontainer berbasis GUI.
  • Deployment Nextcloud: Membuat *Dockerfile* dan *docker-compose.yaml* kustom untuk membangun layanan *cloud storage* (Nextcloud) beserta databasenya secara terisolasi.
  • Deployment Plex Media Server: Menjalankan kontainer Plex menggunakan perintah *Docker run* dengan konfigurasi *network host* dan *volume mapping* untuk manajemen file media.
  • Deployment Laravel & MySQL: Membangun *image* aplikasi web berbasis PHP (Laravel) via *Dockerfile*, mengonfigurasi *web server* (Apache), database (MySQL), dan phpMyAdmin melalui *Docker Compose*.
  • Manajemen & Troubleshooting: Melakukan konfigurasi virtual host pada kontainer, mengelola *volume* data, serta memonitor *resource* (CPU/RAM) kontainer melalui *dashboard* Portainer.

Alat & Teknologi:

Docker & Compose Portainer CE Proxmox / VirtualBox Linux Debian 12 MySQL & phpMyAdmin
